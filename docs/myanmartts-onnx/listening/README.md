# MyanmarTTS — ဖုန်းပေါ်တွင် run ရန် အသံအရည်အသွေး နှိုင်းယှဉ်ချက်

ဖုန်းပေါ်တွင် MyanmarTTS (freococo/MyanmarTTS, CC0) ကို ONNX ဖြင့် run နိုင်မနိုင် စမ်းသပ်ထားသော ရလဒ်များ။
ဖိုင်အားလုံးတွင် စာကြောင်းတစ်ခုတည်းကိုသာ ဖတ်ထားသည် —

> မင်္ဂလာပါ။ မြန်မာစာကို အသံဖြင့် ဖတ်ပြနေပါသည်။

| ဖိုင် | Model အရွယ်အစား | Step | အရည်အသွေး (full precision နှင့် ကွာခြားချက်) |
|---|---|---|---|
| `1_pytorch_original_32steps.wav` | မူရင်း PyTorch | 32 | အခြေခံ (HF demo နှင့် တူ) |
| `2_onnx_fp32_174MB_8steps.wav` | 174 MB | 8 | မကွာ (ONNX = PyTorch ဖြစ်ကြောင်း အတည်ပြုပြီး) |
| `3_onnx_mixed_97MB_8steps.wav` | 97 MB | 8 | ~1% (vocoder ကို full precision ထားသည်) |
| `4_onnx_int8_62MB_8steps.wav` | 62 MB | 8 | ~1% + vocoder ~6% |
| `5_onnx_mixed_97MB_16steps.wav` | 97 MB | 16 | ~1%, step ပိုများသည် |

## နားထောင်ရမည့်အချက်

- **ဖိုင် 3 နှင့် 4** — vocoder ကို int8 ပြောင်းခြင်းကြောင့် အသံကြမ်းခြင်း / တဇီဇီမြည်ခြင်း ကြားရသလား။
  မကြားရပါက app ကို 62 MB ဖြင့် ထုတ်နိုင်သည်။
- **ဖိုင် 1 နှင့် 3/5** — step 32 → 8/16 လျှော့ခြင်းကြောင့် အသံ ကွာခြားသလား။
  Step နည်းလေ ဖုန်းပေါ်တွင် မြန်လေ ဖြစ်သည်။

## အမြန်နှုန်း (ARM CPU, thread 4 ခု၊ ဖုန်းမဟုတ်ပါ)

| Step | အသံ 4.9 စက္ကန့်ကို ထုတ်ရန် ကြာချိန် |
|---|---|
| 8 | 2.8 စက္ကန့် (real-time ထက် မြန်) |
| 16 | 5.3 စက္ကန့် |
| 32 (PyTorch) | 20.6 စက္ကန့် |

ဖုန်းပေါ်တွင် ဤနှုန်းနှင့် တူနိုင်သည် သို့မဟုတ် ၂ ဆခန့်အထိ နှေးနိုင်သည် — ဖုန်းအစစ်ပေါ်တွင် မတိုင်းရသေးပါ။
