RNDTextToSpeech technical report

Android ဖုန်းပေါ်တွင် မြန်မာစာကို အသံထွက်ဖတ်ရန် စမ်းသပ်ချက်။ ဖုန်းအများစု၏ built-in engine တွင် မြန်မာအသံ မပါသဖြင့် Hugging Face ပေါ်ရှိ freococo/MyanmarTTS (PyTorch) ကို ONNX သို့ ပြောင်းပြီး Flutter app ထဲ internet မလိုဘဲ run စေခဲ့သည်။ ထို့ပြင် ဖုန်းတွင်ရှိသော engine အားလုံး (ဘာသာစုံ) ကို ဆက်သုံးနိုင်ပြီး engine နှစ်မျိုးလုံးတွင် waveform၊ player နှင့် download ပေးထားသည်။

Why "speak first, render on demand" (option C)

Android သည် engine က speaker သို့ ဖတ်နေသော အသံကို app သို့ မပေး။ အသံရရန် synthesizeToFile ဖြင့် သီးခြား ထုတ်ခိုင်းရသည်။ ရွေးချယ်စရာ သုံးခုကို နှိုင်းယှဉ်ပြီး product owner က C ကို ရွေးခဲ့သည် (ADR 0005)။

flutter_tts quirks found by reading the plugin source (4.2.5)

Found

awaitSynthCompletion ၏ Future သည် engine error နှင့် stop() တွင် ဘယ်တော့မှ မပြီး — app ထာဝရ စောင့်နေမည်။

Solution

မသုံးဘဲ start/complete/error handler ဖြင့် ကိုယ်တိုင် ခြေရာခံ၊ stop() က စောင့်နေသူကို လွှတ်။

Found

Engine က ဖိုင်ထုတ်မှု မပံ့ပိုးပါက (ERROR ချက်ချင်းပြန်) callback လုံးဝ မလာ။

Solution

5 စက္ကန့်အတွင်း မစပါက မပံ့ပိုးဟု ယူ၊ engine ကို မှတ်ထား၍ ထပ်မစမ်း။ စပြီးပါက အချိန်မကန့်သတ်။

Found

ပုံသေ synthesizeToFile သည် Android 11+ တွင် အသုံးပြုသူ၏ Music folder (MediaStore) သို့ ရေး — ကိုယ်ရေးကိုယ်တာ စာ၏ အသံ ကျန်ရစ်။

Solution

isFullPath: true ဖြင့် app cache ထဲ temp ဖိုင်တစ်ခုတည်း။ မထုတ်မီ ဖျက် (engine မရေးဘဲ "ပြီးပြီ" ဆိုလျှင် ဖိုင်ဟောင်း မဖတ်မိစေ)။

Found

Engine အလိုက် WAV format ကွဲ (Google ~22–24 kHz၊ stereo ဖြစ်နိုင်၊ LIST chunk)။

Solution

Chunk ရှာဖတ်သော WavDecoder → mono 16-bit 44-byte header သို့ isolate ထဲ ပြောင်း။ 16-bit PCM မဟုတ်ပါက fallback။

Found

stop() သည် ဆိုင်းငံ့ speak() ကို 0 (မအောင်မြင်) ဖြင့် ပြီးစေ၊ Android pause မယုံကြည်ရ။

Solution

အသုံးပြုသူ ရပ်ခြင်းကို flag ဖြင့် ခွဲ၍ အမှား မပြ။ Pause ကို app player တွင်သာ ပေး။

Export problems solved

Problem

torch.stft / ISTFT သည် complex tensor ဖြစ်၍ ONNX export မရ။ DFT matrix ဖြင့် graph ထဲ ထည့်ပါက model ~17–32 MB ပိုကြီး။

Solution

Vocos က real/imag ပြန်ပေးပြီး ISTFT (နှင့် recording ၏ STFT) ကို Dart radix-2 FFT ဖြင့် ရေး။ Python နှင့် diff < 1e-5။

Problem

nn.MultiheadAttention ၏ fast-path op ကို ONNX မသိ၊ ပိတ်လျှင်လည်း sequence အရှည် ပုံသေ reshape ဖြစ်။

Solution

Reference encoder ၏ attention ကို in_proj/out_proj weight ဖြင့် ကိုယ်တိုင်ရေး — သင်္ချာ တူ၊ verify ဖြင့် စစ်။

Problem

Step တိုင်း tensor ကို platform channel ဖြင့် Dart ↔ native ကူးပါက နှေး။

Solution

Euler update ကို estimator graph ထဲ ထည့်၊ dt နှင့် cfg ကို input အဖြစ် — step/CFG slider အတွက် re-export မလို။ CFG ၏ cond/uncond ကို batch 2 ဖြင့် တစ်ပြိုင်တည်း။

Problem

v1 တွင် speaker embedding ကို graph ထဲ constant-fold လုပ်ထား၍ အသံ တစ်မျိုးတည်း။

Solution

v2 encoder/estimator ကို speaker[1,256] input ဖြင့် ပြန် export (prenet/vocos byte တူ၍ v1 ဆက်သုံး)။

Problem

Plugin သည် asset ကို ဖိုင်အမည်ဖြင့် cache လုပ်၍ model ပြောင်းလည်း ဖုန်းက အဟောင်းကို တိတ်တဆိတ် သုံးမည်။

Solution

ဖိုင်အမည်တွင် version (_v1_, _v2_) ထည့်၊ ပြောင်းတိုင်း တိုး။

06Player and waveform

  • Waveform — bar တစ်ခု = အချိန် 1/20 စက္ကန့် (ပုံသေ အရေအတွက် မဟုတ်) ဖြစ်၍ ဝါကျ တစ်ခုချင်း၏ waveform ကို followedBy ဖြင့် ဆက်ပြီး ဖတ်နေစဉ်ကပင် ချဲ့ပြ။ ပြချိန်တွင် bar 120 သို့ max-pool ချုံ့။
  • Position — player ၏ position stream (ဝါကျအတွင်း) + ယခင်ဝါကျများ၏ ကြာချိန် = အသံတစ်ခုလုံး၏ position။ Screen rebuild မများစေရန် 100 ms အဆင့်ဖြင့်သာ state ပြင်။
  • Pause — ဝါကျကြား ခေတ္တရပ်ပါက "gate" ဖြင့် နောက်ဝါကျကို တား (ထုတ်ခြင်း ဆက်လုပ်)။ Player ဖွင့်နေချိန်တွင်သာ pause/resume ခေါ် (release ဖြစ်ပြီးသော player ကို မထိ)။
  • Seek — အသံ အပြည့်ရမှသာ (ဖတ်နေစဉ် နောက်ဝါကျ မထုတ်ရသေး)။ နှိပ်/ဆွဲ၍ ရွှေ့၊ မဖွင့်နေစဉ် နှိပ်လျှင် ထိုနေရာမှ စဖွင့်။
  • Download — Storage Access Framework "Save as" dialog (flutter_file_dialog)၊ ဖိုင်အမည် speech_yyyyMMdd_HHmmss.wav။ စာပြင်/engine ပြောင်း/ရပ်ထားသော အသံကို မပေး (စာနှင့် မကိုက်သော ဖိုင် မထွက်စေ)။

09Build and size

Universal release APK ကို တိုင်းရာ 227.8 MB။ Model ~104 MB ကို CPU အားလုံး မျှသုံးပြီး ကျန်သည် ONNX Runtime + Flutter engine ကို CPU ၄ မျိုးအတွက် ထပ်ထည့်ခြင်း။ PC emulator သာ သုံးသော x86/x86_64 ကို packaging.jniLibs.excludes ဖြင့် ဖယ်ထားသည် (ndk.abiFilters သည် --split-per-abi နှင့် ပဋိပက္ခ)။

flutter build apk --release --target-platform android-arm,android-arm64 --split-per-abi
flutter build appbundle --release
  • Models ကို Git LFS (*.onnx) ဖြင့် သိမ်း။ License — assets/models/NOTICE.txt (CC0၊ Vocos MIT၊ FLEURS CC BY 4.0)။
  • Android permission — RECORD_AUDIO၊ TTS_SERVICE query (Android 11+ package visibility)။ Google Play 16 KB page size ကို flutter_onnxruntime ≥ 1.5.1 ဖြင့် ဖြည့်။
  • ARM64 Linux dev machine ပေါ်တွင် aapt2 (x86 only) ကြောင့် APK build မရ — Android build ကို Mac တွင် လုပ်။

10Open items

  • Phone speed & memory — PC ARM တွင်သာ တိုင်းရသေး။ "ဖတ်ပါ" မှ အသံထွက်ချိန်နှင့် အနိမ့်ဆုံး ဖုန်း (RAM/CPU) ကို သတ်မှတ်ရန်။
  • APK size after x86 removal — မတိုင်းရသေး (ခန့်မှန်း arm64 split ~130–140 MB)။
  • Engine audio export — Google TTS / SM Myanmar TTS တွင် ဖိုင်ထုတ်နိုင်မှု၊ ပထမ Play စောင့်ချိန်၊ online voice ၏ ကွဲပြားမှု မစမ်းရသေး။
  • Player on device — position/pause/seek ကို audioplayers ဖုန်းအစစ်ဖြင့် မစမ်းရသေး။
  • Preset male_2 (Kyaw) — လက်ဗွေ တူညီမှု 0.73 သာ၊ ဖုန်းပေါ် နားထောင်ပြီး ပြန်ဆုံးဖြတ်ရန်။
  • Regulatory — ထုတ်ဝေမည့် ဈေးကွက်၊ accessibility၊ AI အသံ ဖော်ပြချက်၊ အခြားသူ၏ အသံ clone ခြင်းဆိုင်ရာ မူဝါဒ မသတ်မှတ်ရသေး။
  • Not persisted — ဘာသာ/engine အသံ ရွေးချယ်မှုကို app ပြန်ဖွင့်လျှင် မမှတ်။
