How the app turns text into speech

The app reads typed text aloud, in Burmese or any language a phone's speech engine supports. Speech can come from two places: an engine already installed on the phone, or our own Burmese voice model that runs inside the app.

စာရိုက်ထည့်ပြီး "ဖတ်ပါ" နှိပ်လျှင် အသံထွက်ဖတ်ပေးသော app ဖြစ်သည်။ အသံကို ဖုန်းတွင် ရှိပြီးသား engine မှ သော်လည်းကောင်း၊ app ထဲတွင် ထည့်ထားသော ကိုယ်ပိုင် မြန်မာအသံ model မှ သော်လည်းကောင်း ထုတ်သည်။

You start the same way every time

Type text→ Choose engine→ Choose language→ Choose voice→ Speak

စာထည့် → Engine ရွေး → ဘာသာရွေး → အသံရွေး → ဖတ်ပါ။ ပုံသေ engine သည် MyanmarTTS ဖြစ်သည်။ ထို့နောက် ရွေးထားသော engine အလိုက် လမ်းကြောင်း နှစ်ခု ခွဲသွားသည်။

Flow A

Phone's own speech engine

Google TTS၊ SM Myanmar TTS ကဲ့သို့ ဖုန်းတွင် ထည့်ထားသော engine

  1. The app finds every installed engine

    ဖုန်းတွင်ရှိသော engine အားလုံးကို စစ်ထုတ်ခြင်းမရှိဘဲ ပြသည်။

  2. You pick a language and a voice

    Engine ပံ့ပိုးသော ဘာသာများနှင့် ထိုဘာသာ၏ အသံများ (Voice 1၊ 2…) ထဲမှ ရွေးသည်။

  3. The engine reads aloud straight away

    "ဖတ်ပါ" နှိပ်သည်နှင့် engine က ချက်ချင်း ဖတ်သည်။ စောင့်စရာ မလို။

  4. Want to replay or download? Tap Play or Download

    ထိုအခါမှ engine ကို တူညီသောစာ ထပ်ဖတ်ခိုင်းပြီး အသံဖိုင် ထုတ်သည် (မလိုဘဲ နှစ်ခါ မလုပ်စေရန်)။

    Engine can give its audioWaveform၊ ပြန်ဖွင့်ခြင်း၊ ဒေါင်းလုဒ် ရသည်။
    Engine can'tအကြောင်းရင်း ပြပြီး Play/Download ကို ဖျောက်သည်။ ဖတ်ခြင်းကို ဆက်သုံးနိုင်သည်။
Flow B

MyanmarTTS inside the app

Hugging Face ပေါ်ရှိ freococo/MyanmarTTS ကို ဖုန်းပေါ်တွင် run နိုင်အောင် ပြောင်းထားသည်

Done once, by us, on a computer

  1. Take the open Burmese voice model

    freococo/MyanmarTTS (public domain၊ CC0) ကို ယူသည်။ မူလက Python ဖြင့်သာ run နိုင်သည်။

  2. Convert it to a phone-friendly format (ONNX)

    ဖုန်းပေါ်တွင် run နိုင်သော ONNX ဖိုင်များအဖြစ် ပြောင်းပြီး မူရင်းနှင့် အသံတူကြောင်း စစ်သည်။

  3. Shrink it without hurting the sound

    174 MB မှ ~104 MB သို့ ချုံ့သည်။ ဗားရှင်း ၅ မျိုးကို နားထောင်ပြီး အကောင်းဆုံးကို ရွေးသည်။

  4. Prepare 9 ready-made voices

    မူလအသံ Thiri နှင့် ကျား ၄ / မ ၄ (Google FLEURS အသံဖမ်းချက်များမှ)။

Every time you tap Speak, on the phone

  1. Split the text into sentences

    စာရှည်ကို ဝါကျအလိုက် ခွဲသည်။ Internet မလို — စာသည် ဖုန်းအပြင် မထွက်။

  2. The model turns each sentence into sound

    ရွေးထားသော အသံ (သို့မဟုတ် ကိုယ်တိုင် အသံသွင်းထားသော အသံ) ဖြင့် ထုတ်သည်။

  3. Plays while the next sentence is being made

    ဝါကျ ၁ ဖွင့်နေစဉ် ဝါကျ ၂ ကို ကြိုထုတ်ထားသဖြင့် ဆက်တိုက် ကြားရသည်။ Waveform တဖြည်းဖြည်း ပေါ်လာသည်။

  4. Replay, pause, seek or download

    ပြီးလျှင် ပြန်ဖွင့်၊ ခေတ္တရပ်၊ waveform ပေါ်နှိပ်၍ ရွှေ့၊ WAV ဖိုင် ဒေါင်းလုဒ် လုပ်နိုင်သည်။

Where both flows end up

Hear itအသံထွက်ဖတ်သည်
See itWaveform နှင့် ဖွင့်နေသော နေရာ
Control itပြန်ဖွင့်၊ ခေတ္တရပ်၊ ရွှေ့
Keep itWAV ဖိုင်အဖြစ် ဒေါင်းလုဒ်
